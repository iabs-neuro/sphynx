# +sphynx engine — ultra bug audit (R2025)

Многоагентный адверсариальный аудит движка (`+sphynx`, без `+app`), R2025b.
10 finder-агентов по пакетам, каждая находка верифицирована отдельным
агентом с задачей опровергнуть. Итог: **12 кандидатов -> 8 CONFIRMED, 0 UNCERTAIN, 4 отсеяно.**

Общий вывод синтезатора: движок структурно здоров, архитектурного переписывания
не требует; все дефекты — локальные, точечные. Опаснее всего не краши, а
**тихие неправильные ответы** (RM-ANOVA, per-act скорость, обнуление акта).

## Темы

- **Небезопасная обработка синтезированного/имputированного центра тела** — #1 и #3 из одного корня (Point.Center = nKept+1 указывает на несуществующую строку BPV/BodyPartsTraces; guard проверяет пустоту, а не валидность индекса).
- **Тихие неверные ответы вместо явных ошибок** — #2, #3, #4: правдоподобный, но неправильный вывод без единого warning. Самый опасный класс.
- **Позиционная привязка к таблицам/структам MATLAB** — #2 (фикс. строка ranova), #5 (набор полей) ломаются при дрейфе формы производителя.
- **Хрупкость на вырожденных входах в preprocess** — #6, #7, #8.
- **Дыры в тестах** — readObjects всегда падает и RM-ANOVA-строка неверна => эти пути никогда не гонялись против реальных производителей/эталонных чисел.
